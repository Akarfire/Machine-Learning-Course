### Установка
#### 1. Создать виртуальное окружени 

```bash
python -m venv .venv
```

#### 2. Активировать виртуальное окружение

```shell
./.venv/Scripts/activate
```

#### 3. Установить библиотеки

```shell
pip install -r "requirements.txt"
```

#### 4. Запустить скрипт загрузки данных
```bash
python .\SetupData.py 
```
